# 🎉 Whises — Website Ucapan Ulang Tahun

Proyek sederhana berupa **website ucapan ulang tahun interaktif**, berisi halaman ucapan, musik, dan efek bunga.  
Cocok untuk diberikan sebagai hadiah digital spesial untuk orang tersayang. 💝

## 🌐 Demo
Setelah diunggah ke GitHub Pages, kamu bisa membukanya lewat:
```
https://username.github.io/whises/
```
> Ganti `username` dengan nama pengguna GitHub kamu.

## 📂 Struktur Folder
```
index.html              → Halaman utama
buku-ucapan.html        → Halaman buku ucapan
kado-main/              → Folder berisi script & efek tambahan
serta_mulia.mp3/.ogg    → Musik latar
sampul design buku.png  → Gambar sampul ucapan
```

## 🛠️ Cara Menjalankan di GitHub Pages
1. Buat repository baru di GitHub, misalnya `whises`
2. Upload semua file dari proyek ini
3. Buka **Settings → Pages**
4. Di bagian **Source**, pilih:
   - Branch: `main`
   - Folder: `/ (root)`
5. Klik **Save**  
   Tunggu 1–2 menit, lalu situsmu akan aktif di:
   ```
   https://username.github.io/whises/
   ```

---

✨ Selamat mencoba!  
Kalau ingin menambahkan efek animasi atau musik lain, cukup ganti file di dalam folder `kado-main/`.
